# Panorama-da-Sa-de-P-blica-em-S-o-Paulo-2000-2025-
Dashboard em Power BI que analisa a relação entre cobertura de atenção básica (ICSAB) e mortalidade geral nos 645 municípios de São Paulo (2000-2025). Dados públicos do DATASUS/TABNET-SP, tratados com Power Query e DAX, com mapa geográfico customizado e análise de correlação.
